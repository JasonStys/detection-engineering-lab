# Security policy

This defensive lab accepts only normalized authorized input and includes synthetic data. Do not use it to attack/scan others or interpret a rule match as a hiring, disciplinary or incident verdict. No autonomous action is taken.

Do not post operational logs, credentials or personal data in issues. Use GitHub's **Report a vulnerability** private channel for this public repository when enabled. If unavailable, contact [Jason Stys on LinkedIn](https://www.linkedin.com/in/jason-stys-31b30b351/) with a nonsensitive description and arrange a private channel; never send secrets. Ordinary questions can use repository issues without sensitive attachments.

Support covers the latest validated main revision; old versions are not automatically maintained. No response SLA is promised. Review [security boundaries](docs/threat-model.md), update dependencies, and rerun unsuppressed scans. A green workflow is not a universal safety guarantee. Local normalized databases/reports are not encrypted and must remain private when using anything other than the provided fictional corpus.
